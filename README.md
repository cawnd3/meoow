# Meoow Browser

Собственный браузер на базе **Electron + Chromium** с закладками, историей и встроенным поиском **Meoow Search**.

![stack](https://img.shields.io/badge/Electron-Chromium-8b5cf6) ![status](https://img.shields.io/badge/status-ready-22c55e)

## Возможности

- Собственный поиск **Meoow Search**: поисковая страница + выдача результатов (параллельная агрегация Bing RSS → Bing HTML → DuckDuckGo → DuckDuckGo Lite из главного процесса, без сторонних ключей)
- **Поиск по картинкам и видео**: режимы «Все» / «Картинки» / «Видео» на странице результатов (Bing Images и Bing Videos async, видео с превью и длительностью, без API-ключей)
- **Защита от фишинга**: проверка подозрительных сайтов перед переходом — перехват подделок под известные сервисы (paypal, google, tinkoff, sberbank и др.) и рискованных доменов
- **Meoow AI** — ИИ-помощник в браузере (по кнопке в тулбаре или `Ctrl+I`): отвечает на вопросы, считает примеры, называет время и дату, открывает сайты и выполняет поиск по команде. По умолчанию — «умный синтез» из нескольких источников поиска; при подключении своего ИИ-ключа (меню → Настройки → ИИ-помощник, любой OpenAI-совместимый сервис: Groq, OpenRouter, Gemini, Ollama) — настоящие живые онлайн-ответы с учётом контекста разговора и найденных страниц
- **Быстрый доступ** (speed dial): часто посещаемые сайты на стартовой — логотип и название сайта без рамок, открытие одним кликом
- **Логотипы сайтов** — сайт узнаётся по своему favicon на вкладках, в выдаче поиска, в закладках, истории, подсказках и на плитках быстрого доступа
- **Полоса прокрутки сайтов** — заметный скроллбар справа на любом сайте, даже когда Windows прячет системные полосы (отключается в настройках)
- **Тёмные сайты** — переключатель в настройках принудительно затемняет открытые страницы
- **Блок уведомлений** — сайты не могут запрашивать разрешение на уведомления (по желанию в настройках)
- **Подсказки в адресной строке** из собственной истории и закладок
- **Поиск на странице (Ctrl+F)** с подсветкой и счётчиком совпадений
- **Автообновления**: установленная версия сама проверяет обновления на GitHub, скачивает их в фоне и предлагает перезапуск (для установщика NSIS; portable-версия не самообновляется)
- **Полный экран (F11)** и **скачивание файлов** с выбором папки сохранения
- Подсказки при вводе (автодополнение), поиск нажатием Enter
- Многовкладочный интерфейс: вкладки можно **перетаскивать** мышью для смены порядка (с анимацией)
- Полноценный движок Chromium (совместимость с сайтами)
- Закладки (панель + менеджер, сохраняются между сессиями)
- История посещений (до 500 записей, удаление отдельных записей)
- Умная адресная строка (адрес ИЛИ поиск Meoow)
- Навигация: назад / вперёд / обновить / домой (единая история на уровне вкладки работает и между поиском, и веб-страницами)
- Печать страниц, контекстное меню
- **Рукотворный дизайн** — интерфейс в стиле «тёплой осенней библиотеки» (эспрессо-хромированный тулбар с кожей, кремовая бумага страниц, серифная вывеска), ничем не похож на типовой «ИИ-шаблон»; светлая и тёмная темы
- Настройки (меню → «Настройки»): поисковая система, новая вкладка (поиск / пустая), масштаб страниц 100–150%, светлая / тёмная тема, очистка данных, сброс настроек, переключатели фич (полоса прокрутки сайтов, тёмные сайты, защита от фишинга, блок уведомлений) и секция **ИИ-помощник** (эндпоинт, ключ API, модель)

## Установка и запуск

```bash
npm install
npm start
```

## Горячие клавиши

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+T`  | Новая вкладка |
| `Ctrl+W`  | Закрыть вкладку |
| `Ctrl+L`  | Фокус в адресной строке |
| `Ctrl+R`  / `F5` | Перезагрузить |
| `Ctrl+D`  | Добавить в закладки |
| `Ctrl+H`  | История |
| `Ctrl+F`  | Найти на странице (Enter — далее, Shift+Enter — назад, Esc — закрыть) |
| `Ctrl+I`  | Открыть / закрыть Meoow AI |
| `F11`     | Полный экран |

## Meoow AI

ИИ-помощник, встроенный прямо в браузер:
- **Общается с вами** — «привет», «как дела», «спасибо», «пока»; поддерживает продолжение темы («ещё», «дальше», «подробнее» — добирает новые источники по тому же вопросу и снова спрашивает ИИ).
- **Отвечает на вопросы** — по умолчанию ответ собирается из текстов нескольких найденных источников (сниппеты) и показывается со ссылками; например, «найди про ядерную физику» или «что такое квантовый компьютер».
- **Живые онлайн-ответы (ключ)** — если в настройках (ИИ-помощник) указан адрес OpenAI-совместимого сервера и ключ API, вопрос уходит на модель вместе с найденными сниппетами и последним контекстом беседы — ответы становятся настоящими, осмысленными и по делу. Годится любой сервис с OpenAI-совместимым эндпоинтом: Groq, OpenRouter, Google Gemini (бесплатные тарифы), локальный Ollama и т.п.
- **Считает примеры** — «сколько будет 17*249» (локально, без сети).
- **Называет время и дату** — «который час», «какая сегодня дата».
- **Открывает сайты по команде** — «открой Википедию» / «открой YouTube».
- **Подсказывает ресурсы** — «топ сайтов для учёбы».
- Панель открывается кнопкой в тулбаре или `Ctrl+I` (Esc или клик вне панели закрывает). Ответы со ссылками кликабельны — открываются в новой вкладке. Ключ хранится только в файле настроек на этом компьютере; без ключа вопрос уходит только в поиск.

## Установленное приложение (.exe)

Готовые сборки лежат в `dist/`:

- **`Meoow-Setup-1.0.3.exe`** — установщик (стандартный мастер: выбор папки, ярлык на рабочем столе и в меню «Пуск»).
- **`Meoow-Portable-1.0.3.exe`** — портативная версия (без установки).

Установщик собирается без подписи кода (для подписи нужен коммерческий сертификат), поэтому Windows/SmartScreen может показать предупреждение. Чтобы продолжить: **More info → Run anyway**.

## Сайт скачивания

Статический лендинг с кнопками скачивания лежит в `site/` (в `site/downloads/` — свежие копии exe-файлов). Открыть локально: просто открыть `site/index.html` в браузере. Для публикации достаточно выложить папку `site/` на любой статический хостинг или GitHub Pages (файлы уже готовы, ничего настраивать не нужно).

## Поиск Meoow Search

- Стартовая страница (кнопка «Домой» и новая вкладка) — фирменный экран Meoow: осеннее логотип «Meoow» (тёплая осенняя палитра), строка поиска с подсказками (поиск по Enter), ряд часто посещаемых сайтов (логотип + название, без рамок) и футер со ссылками на историю и настройки; сайты в подсказках и на плитках показываются со своими логотипами.
- Любой запрос в адресной строке или на стартовой странице открывает страницу результатов в стиле Google SERP: карточки с заголовками, адресами и сниппетами.
- Вкладки **«Все» / «Картинки» / «Видео»** переключают выдачу: текстовые результаты, сетка изображений или сетка видео с превью и длительностью (по клику открывается источник/видео).
- Результаты собираются главным процессом браузера параллельно из нескольких движков (Bing RSS → Bing HTML → DuckDuckGo → DuckDuckGo Lite) и объединяются в один список с дедупликацией — выдача заметно полнее, при недоступности одного провайдера остальные подхватывают. Автоподсказки: Google Suggest → DuckDuckGo. Работает без API-ключей, в строке результатов указаны источники.
- Запросы-адреса (например, `example.com` или `https://...`) открываются как обычно.

## Защита от фишинга

- Перед открытием страницы браузер проверяет адрес на признаки подделки.
- Перехватываются домены, похожие на известные сервисы (paypal, google, microsoft, apple, amazon, tinkoff, sberbank, roblox, telegram, vk и др.), рискованные зоны (`.top`, `.xyz`, `.click`, `.gq`, `.tk`) с чувствительным содержимым, а также незащищённый HTTP для сайтов с логинами и оплатой.
- При обнаружении показывается предупреждение: можно вернуться назад или продолжить переход по собственной ответственности (выбор запоминается для этой вкладки и этого адреса).

## Сборка установщика (Windows)

```bash
npm install --save-dev electron-builder
npm run dist     # создаёт dist/Meoow-Setup-1.0.3.exe и Meoow-Portable-1.0.3.exe
```

Сборка настроена через `build/` (иконки `build/icon.ico`/`icon.png`) и `afterPack`-хук
(`build/after-pack.js`), который вписывает в `Meoow.exe` иконку и информацию о версии без
реальной подписи кода (это обходит невозможность создания симлинков в winCodeSign без прав администратора).

## Регрессионный тест

```powershell
$env:MEOOW_TEST='1'; npm start   # вывод TEST_OUT ... / TEST_ERRS в консоль, приложение закроется само
```

Покрыты: главная (осенний логотип, цвета, шапка/футер), наложение панелей (хит-тест), вкладки, поиск, автоподсказки, реальный сетевой поиск, поиск картинок, защита от фишинга (чистые/подозрительные адреса), навигация с возвратом к поиску, размер webview, страница ошибки, закладки, менеджер, настройки и переключатели фич (полоса прокрутки, тёмные сайты, защита, уведомления), ИИ-панель (синтез и локальные команды), поиск на странице (Ctrl+F), подсказки адресной строки и speed dial.

## Структура

```
Meoow/
├── main.js          # Главный процесс Electron (окно, IPC, хранилище, поисковый бэкенд, скачивания)
├── preload.js       # Безопасный мост между UI и главным процессом
├── src/
│   ├── index.html   # Интерфейс браузера (табы, тулбар, страница поиска, меню, настройки, findbar)
│   ├── styles.css   # Стили (включая тёмную тему)
│   └── renderer.js  # Логика UI (табы, навигация, закладки, история, выдача поиска, настройки, speed dial)
└── site/            # Сайт скачивания (index.html + styles.css + downloads/)
```

## Примечание

Браузер использует `webview` (Chromium) и работает только внутри Electron. Закладки, история и настройки хранятся в папке данных приложения (`app.getPath('userData')/meoow-data`). Скачивание файлов запрашивает куда сохранить файл (в тестовом режиме MEOOW_TEST сохраняет молча в `%TEMP%`).
